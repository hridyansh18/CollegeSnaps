# 📸 CollegeSnaps

> **Live Website:** https://collegesnaps.netlify.app
> **GitHub Repository:** https://github.com/hridyansh18/CollegeSnaps

CollegeSnaps is a modern college gallery platform built to showcase campus events, memories, and achievements in an organized and visually appealing way. It provides students, faculty, and visitors with an easy way to browse event albums and relive memorable moments.

---

## ✨ Features

* 📷 Beautiful and responsive gallery
* 📂 Event-wise album organization
* 🖼️ Album Details page with image previews
* ⚡ Fast and modern React interface
* 📱 Fully responsive for mobile, tablet, and desktop
* 🎨 Clean and attractive UI
* 🔍 Easy navigation between albums
* 🚀 Optimized for performance

---

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/hridyansh18/CollegeSnaps.git
```

### Navigate to the project

```bash
cd CollegeSnaps
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
